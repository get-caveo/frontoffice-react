# 📍 Instructions : Placer votre modèle 3D ici

## Fichier attendu
**Nom** : `wine-bottle.glb`  
**Format** : GLB (ou GLTF)

## Comment obtenir un modèle 3D de bouteille

### Option 1 : Télécharger gratuitement
Sites recommandés :
- https://sketchfab.com/search?q=wine+bottle&type=models (chercher "wine bottle" et filtrer "Downloadable")
- https://free3d.com/3d-models/wine-bottle
- https://www.cgtrader.com/free-3d-models/wine-bottle

### Option 2 : Créer avec Blender (gratuit)
1. Télécharger Blender : https://www.blender.org/download/
2. Modéliser une bouteille
3. Exporter : File → Export → glTF 2.0 (.glb)
4. Nommer le fichier : `wine-bottle.glb`

### Option 3 : Convertir un modèle existant
Si vous avez un fichier .obj, .fbx, ou autre :
- En ligne : https://products.aspose.app/3d/conversion
- Avec Blender : Import → Export en GLB

## Une fois le modèle prêt
1. Placer `wine-bottle.glb` dans ce dossier (public/models/)
2. Lancer `npm run dev`
3. Le modèle apparaîtra automatiquement en fond de la page d'accueil

## Caractéristiques recommandées
- ✅ 5 000 - 20 000 polygones maximum
- ✅ Textures 1024x1024 ou 2048x2048
- ✅ Modèle centré à l'origine
- ✅ Format GLB (compact, optimisé)

Consultez GUIDE-3D-MODEL.md pour plus de détails.
